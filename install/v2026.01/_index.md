# BSH 各产品组安装操作指南索引 V2026.01

## 一、使用说明

本索引是 LLM 执行安装引导的**一级分诊入口**。

**执行方法**：
1. 用户来电描述需安装的产品 → 查阅"三、一级分流表"定位对应文件
2. 加载对应安装树文件，按其内部步骤逐步引导
3. 遇到"返回首页产品组选择"时回到本索引重新分流

**文件体系**：
- 本索引文件 × 1
- 独立安装树文件 × 16（每个产品一个 MD）
