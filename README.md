# Service Knowledge Management

BSH service knowledge artifacts generated from PPT fault-tree sources.

## Contents

- `outputs/bsh-flow-knowledge-flat/`: full BSH fault-tree knowledge output, kept as a flat upload-friendly directory.
- `outputs/bsh-flow-knowledge-flat.zip`: zipped full output.
- `outputs/bsh-install-tree-flat/`: standalone split of `各产品组安装操作指南-new.pptx`, kept flat.
- `outputs/bsh-install-tree-flat.zip`: zipped standalone install-tree output.
- `scripts/`: local conversion and Volcengine import helper scripts.

## Current Batch

- Full batch: 35 PPTX files, 35 index files, 379 fault-tree files, 414 manifest rows.
- Install standalone batch: 1 PPTX file, 1 index file, 4 tree files, 5 manifest rows.

See the report files under each output directory for source mapping, quality checks, and omission audits.
